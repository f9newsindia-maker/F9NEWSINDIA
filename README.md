## 🚀 मुख्य विशेषताएँ (Key Features)

### 1. होम स्क्रीन एवं ब्रेकिंग न्यूज़ (Home & Live Ticker)
- आधिकारिक F9NEWSINDIA लोगो एवं ब्रांड रंग (लाल `#dc2626`, नीला `#1e3a8a`, सफ़ेद `#ffffff`, गहरा स्लेट `#0f172a`)।
- **लाइव ब्रेकिंग न्यूज़ टिकर** (पॉज़, प्ले एवं टेक्स्ट-टू-स्पीच ऑडियो वाचन)।
- **10 प्रमुख श्रेणियां:**
  - देश (National)
  - महाराष्ट्र (Maharashtra)
  - उत्तर प्रदेश (Uttar Pradesh)
  - राजनीति (Politics)
  - अपराध (Crime)
  - मनोरंजन (Entertainment)
  - खेल (Sports)
  - बिजनेस (Business & Market)
  - टेक्नोलॉजी (Technology & AI)
  - स्थानीय समाचार (Local / District news)
- **ऑडियो न्यूज़ रीडर ("ख़बर सुनें"):** वेब स्पीच एपीआई द्वारा हिंदी में समाचार वाचन।
- **1-टैप WhatsApp शेयरिंग** और ऑफ़लाइन बुकमार्क।

### 2. वीडियो न्यूज़ एवं यूट्यूब 24x7 हब (Video News & YouTube Hub)
- F9NEWSINDIA आधिकारिक यूट्यूब चैनल का सीधा एकीकरण।
- **24x7 F9 लाइव टीवी ब्रॉडकास्ट प्लेयर**।
- **F9 News Shorts** (60-सेकंड्स वर्टिकल त्वरित बुलेटिन)।
- ऐप से सीधे यूट्यूब वीडियो खोलने की सुविधा।

### 3. संवाददाता एवं पत्रकार पोर्टल (Reporter Panel)
- जमीनी पत्रकारों एवं जिला संवाददाताओं हेतु न्यूज़ सबमिशन फॉर्म।
- शीर्षक, श्रेणी, जिला/शहर, फोटो URL, वीडियो लिंक और ब्रेकिंग फ्लैग।
- ड्राफ्ट सहेजने एवं संपादकीय स्वीकृति स्थिति (Under Review, Published, Rejected) ट्रैक करने की सुविधा।
- **आधिकारिक F9 डिजिटल प्रेस पहचान पत्र (Press ID Card)**।

### 4. प्रशासक एवं संपादक डैशबोर्ड (Admin Dashboard)
- सुरक्षित पिन-प्रोटेक्टेड लॉगिन (डिफ़ॉल्ट मास्टर पिन: `9999`)।
- संवाददाताओं द्वारा प्रेषित समाचारों को एक क्लिक में स्वीकृत या अस्वीकृत करना।
- ब्रेकिंग न्यूज़ टिकर में तत्काल नए अलर्ट जोड़ना और हटाना।
- पुश नोटिफिकेशन ब्रॉडकास्ट सिमुलेशन।
- रियल-टाइम पाठक संख्या, व्यूज़ एवं एंगेजमेंट मेट्रिक्स।
- मोबाइल-अनुकूलित (Mobile Responsive) संपादक कंसोल।

### 5. मुद्रीकरण एवं विज्ञापन (Monetization & AdMob)
- **Google AdMob इंटीग्रेशन** (बैनर एवं इंटरस्टिशियल टेस्ट यूनिट आईडी)।
- प्रायोजित लेखों (Sponsored News) पर स्पष्ट लेबलिंग।
- डिजिटल मार्केटिंग एवं विज्ञापन दर सूची (Rate Card)।
- सीधे व्हाट्सएप पर विज्ञापन लीड जनरेशन फॉर्म।

### 6. एंड्रॉइड PWA एवं ऑफ़लाइन क्षमता
- होम स्क्रीन इंस्टॉलेशन (Add to Home screen)।
- सर्विस वर्कर द्वारा ऑफ़लाइन समाचार कैशिंग (खराब नेटवर्क में भी पढ़ने योग्य)।
- Google Play Store हेतु APK एवं AAB पैकेजिंग के लिए पूर्णतः अनुकूल।

## 🛠️ इंस्टॉलेशन एवं लोकल डेवलपमेंट (Local Setup)

### आवश्यकताएं (Prerequisites)
- [Node.js](https://nodejs.org/) (संस्करण 18 या उससे अधिक)
- npm या pnpm

### चरण (Steps)

```bash
# 1. रिपॉजिटरी क्लोन करें
git clone https://github.com/f9newsindia-maker/F9NEWSINDIA.git
cd F9NEWSINDIA

# 2. सभी निर्भरताएं (Dependencies) इंस्टॉल करें
npm install

# 3. डेवलपमेंट सर्वर शुरू करें
npm run dev

# 4. ब्राउज़र में http://localhost:3000 खोलें
```

### प्रोडक्शन बिल्ड (Production Build)

```bash
npm run build
```

## 📱 Android APK और AAB फाइल कैसे बनाएं? (Play Store Guide)

### तरीका 1: PWABuilder द्वारा (सरलतम विधि)
1. [PWABuilder.com](https://www.pwabuilder.com/) पर जाएं।
2. अपने होस्ट किए गए ऐप का URL दर्ज करें।
3. **Package for Android** पर क्लिक करें।
4. पैकेज नाम में `com.f9newsindia.app` दर्ज करें।
5. **Download Package** दबाएं — आपको Google Play Console के लिए तैयार `.aab` फ़ाइल और सीधे मोबाइल में टेस्ट करने हेतु `.apk` फ़ाइल प्राप्त हो जाएगी।

### तरीका 2: Bubblewrap CLI द्वारा
```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest=https://YOUR_APP_URL/manifest.webmanifest
bubblewrap build
```
